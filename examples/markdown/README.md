# Markdown Example

This example demonstrates processing markdown files containing embedded data tables
and CSV blocks with Tabula scripts.

## What it does

1. Processes a markdown table calculating item totals (price × amount)
2. Calculates the sum of all items
3. Applies monetary formatting to price and total columns
4. Demonstrates multiple ways to associate **Tabula** scripts with data blocks in markdown
